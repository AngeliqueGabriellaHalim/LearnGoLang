LITERALS:
syntax that express a particular value
1. integer literal : expressing integer value
  > 1254 : base 10 integer literal
  > 0b0100 : binary number
  > 0o72 : octal number
  >0xFF: hexa number
2. FLOAT literal:
  > 12.3, base 10 
  > 0x74.2, hexa number
  > 12.3e4, decimal with exponent
  > 0x74.2p3, hexa with exponent

3. rune literal: rep CHAR
> 'a' : rune literal
> '\n' : escape sequence

4. string literal:
  a. interpreted string literal : 
    - use ""
    - escape seq is usable
    > "Hello, world\n"
  b. raw string literal:
    - use ``
    - escape seq not usable
    > `This is a "raw string"`
    - use to create multi line string
  c. boolean: rep Boolean val : true or false

  }
  fmt.Println(i)
}

we can label the continue and break
n := 5
outer: for i := 0; i < n; i++ {
  for j := 0; j < n; j++ {
    if i < j {
      continue outer
    }
    fmt.Println(i, j)
  }
}
